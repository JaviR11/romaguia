# Guía Roma · 15–19 sep 2026

Guía de viaje móvil (estática) para el itinerario por Roma.

## Abrir en el móvil

**https://javir11.github.io/romaguia/**

### Añadir a la pantalla de inicio

- **Android (Chrome):** menú ⋮ → *Añadir a pantalla de inicio* / *Instalar app*
- **iPhone (Safari):** compartir → *Añadir a pantalla de inicio*

## Desarrollo local

Abre `index.html` o sirve la carpeta:

```bash
npx --yes serve . -p 3000
```

Archivos principales: `index.html`, `data.js`, `app.js`.
